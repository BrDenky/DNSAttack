## 3. Network Commands (Windows)

### Flush DNS Cache
Clear the local DNS resolver cache:
ipconfig /flushdns

### Static ARP Management (Defense against ARP Spoofing)

# Add Static ARP Entry
# Usage: netsh interface ipv4 add neighbors "Interface Name" <Gateway IP> <Gateway MAC>
netsh interface ipv4 add neighbors "Ethernet0" 192.168.220.2 00-50-56-f6-56-f6

# Delete Static ARP Entry
# Remove the static entry to restore dynamic ARP resolution:
netsh interface ipv4 delete neighbors "Ethernet0" 192.168.220.2
